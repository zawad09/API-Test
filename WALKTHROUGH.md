## Likely Evaluator Questions (with short answers)

1. **Why is the percentage weighted instead of a simple count?**
   A high-importance skill matters more to the employer than a low-importance one; weighting also distinguishes "half-learned" from "missing" because partial levels earn partial credit.
2. **Why is the AI only an explanation layer?**
   The scoring is deterministic for reliability, repeatability, testability and cost. The AI layer only *explains* already-saved results in natural language, with a rule-based fallback - so the core numbers stay trustworthy even if the provider fails.
3. **How do you prevent users reading each other's analyses?**
   Every analysis query is scoped by the authenticated user id, and a mismatch throws 403; there is no endpoint that accepts a userId.
4. **How are passwords stored?**
   bcryptjs with 10 salt rounds, `select: false` in Mongoose so the hash is never fetched unless login explicitly requests it, and a toJSON transform strips it from responses.
5. **What happens if a job has no required skills?**
   Total max score is 0, so the engine safely returns 0% with empty lists instead of dividing by zero (tested).
6. **How do tests avoid touching real data?**
   The Jest setup starts its own in-memory MongoDB and wipes collections between tests; production/Atlas is never used by tests.
7. **What does the AI layer use, and what happens if it fails?**
   Any OpenAI-compatible free-tier provider (Google AI Studio or Groq) configured through env vars - nothing paid required. If it is disabled, slow or failing, the AI endpoints answer with the built-in rule-based coach and the `source` field shows which one responded. AI suggestions never contain invented course names or links.

## Recording Tips

- Record at 1080p; zoom Postman to ~120% so the JSON is readable.
- Keep each API call on screen long enough to read the `success` and `data` fields.
- If a request fails live, say "and this is exactly why we have tests" and move on - do not edit code while recording.
- Mention honestly that job/company names are sample data ("sample" suffix is intentional).
